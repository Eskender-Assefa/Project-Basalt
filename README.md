# Project-Basalt

Basalt is a personal project that is born out of a hackathon that never came to be. On the dates of April 24 - 26, 2026, the German Federal Ministry for Research, Technology, and Space (BMFTR) in coordination with LeitWert GmbH and other ISPs planned to conduct the hackathon, for which I had intensely prepared for 2 weeks and gathered a team. Then... 1 day before the event... it got cancelled. Reason: Not enough participants.

But I had given it so much that I just couldn't throw it away and move on. So I developed it further, researched it better, and got more curious.
